PharmaGest Pro

Un système d'information complet pour la gestion moderne des pharmacies. Cette application SPA (Single Page Application) assure une fluidité totale dans la gestion des stocks, des ventes et le suivi des ordonnances.

Technologies

React JS Laravel API MySQL Axios Tailwind

Fonctionnalités Clés

Gestion de Stock

Suivi en temps réel des médicaments, alertes de péremption et réapprovisionnement automatique.

Point de Vente (POS)

Interface de caisse rapide développée en React pour traiter les ventes et imprimer les tickets.

Traçabilité

Historique complet des ordonnances et gestion des dossiers patients.
